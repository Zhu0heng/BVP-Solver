# Метод продолжения по параметру на Python

Проект по численным методам решения краевых задач с использованием метода продолжения по параметру.

## Описание

Этот проект реализует метод продолжения по параметру (continuation method) для решения нелинейных краевых задач для обыкновенных дифференциальных уравнений. Проект включает в себя:

- Символьные вычисления с SymPy для безопасного парсинга математических выражений
- Численные методы с NumPy и SciPy
- Графический интерфейс на PyQt5
- Сохранение и загрузка задач в формате JSON
- Визуализация результатов с Matplotlib

## Формат граничных условий

Граничные условия записываются в естественной форме:
- `xi(a)` — значение xi в точке a (начало интервала)
- `xi(b)` — значение xi в точке b (конец интервала)

Примеры:
- `x1(a) = 2` — x1(a) = 2
- `x2(a) = 0` — x2(a) = 0
- `x1(b) = 1.0738644361` — x1(b) = 1.0738644361
- `x2(b) = -1.0995343576` — x2(b) = -1.0995343576
- `x1(a) = x4(a)` — x1(a) = x4(a) (связь между переменными)
